# OLMOA Remaining External Blockers & Future Roadmap

## 1. 개요
본 문서는 OLMOA 플랫폼의 내부 소프트웨어 아키텍처 및 D1 데이터 파이프라인 완성과는 별개로, 실제 글로벌 상용 서비스 런칭을 위해 법적·계약적·외부 서비스 의존성으로 인해 즉시 활성화할 수 없는 외부 차단 요소(External Blockers)와 향후 로드맵을 투명하게 보고한다.

---

## 2. 외부 의존성 차단 요소 (External Blockers)

### 1. 실물 신용카드 / 간편결제 PG사 상용 계약
- **현황**: 카카오페이, 토스페이, 글로벌 신용카드 결제 UI 및 에스크로 결제 승인 파이프라인은 완성되어 작동 중이나, 실제 고객의 신용카드에서 대금을 인출하는 PG망 연동은 법인 사업자등록, 통신판매업신고, PG사(KG이니시스, 토스페이먼츠 등) 가맹점 계약 및 심사가 선행되어야 함.
- **조치 방안**: 법인 정식 설립 및 가맹점 심사 완료 즉시 Webhook 서명 검증 모듈과 운영 API 키를 주입하여 실망 전환.

### 2. 관세청 유니패스(UNI-PASS) 및 해외 배송사 API 계약
- **현황**: 판매자의 송장 번호 입력 및 고객 실시간 추적 바인딩은 100% 동작하지만, 실제 선박/항공 세관 통관 부호 검증 및 배송사(CJ대한통운, EMS, FedEx)의 실시간 물리적 위치 GPS 추적은 공식 B2B API 키 발급이 필요함.
- **조치 방안**: 정식 물류 계약 체결 후 배송 추적 Webhook 연동.

### 3. 공식 커스텀 도메인 DNS 바인딩
- **현황**: 현재 모든 서비스는 `*.workers.dev` 서브도메인에서 완벽하게 동작 중임.
- **조치 방안**: `olmoa.com` 도메인 구입 후 Cloudflare Custom Domains 기능으로 `store.olmoa.com`, `partner.olmoa.com`, `admin.olmoa.com`, `api.olmoa.com` 라우팅 일괄 전환.

---

## 3. 중장기 고도화 로드맵

1. **글로벌 다국어 현지화 (i18n)**: 영어, 일본어, 스페인어 사전 번역 및 통화 환율 API 자동 갱신.
2. **복식부기 실시간 회계 원장 역분개**: 주문 취소/부분 환불 시 `ledger_entries` 차변/대변 자동 회계 전표 발행 고도화.
3. **Flutter 모바일 애플리케이션 빌드**: Storefront 및 Partner 기능을 Flutter iOS/Android 네이티브 바이너리로 패키징.
