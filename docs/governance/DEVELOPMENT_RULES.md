# 개발 원칙 및 엔지니어링 헌장 (DEVELOPMENT_RULES.md)

## 1. 10대 불변 개발 원칙 (Core Invariants)
1. **Mock 데이터 금지 원칙**: 프론트엔드 단독 가짜 데이터 처리를 엄격히 금지하며 모든 거래 및 상태 변경은 서버 API와 데이터베이스 트랜잭션을 거쳐야 한다.
2. **부동소수점 화폐 연산 금지**: 화폐 금액 계산 시 `float`/`double` 타입 사용을 일체 불허하며 정수형 `BIGINT`로 원단위/센트단위를 다룬다.
3. **단일 파일 250줄 제한**: 코드 및 문서의 유지보수성과 가독성을 위해 단일 파일의 길이는 250라인 이하로 엄격히 모듈화한다.
4. **완벽한 멀티테넌시 격리**: 파트너 간 데이터는 SQL 쿼리 레벨에서 `partner_id` 조건을 필수로 강제한다.
5. **초과 판매 제로 통제**: 재고 감산은 데이터베이스 락 경합 없이 Redis 7 단일 스레드 Lua 스크립트로 원자적 처리한다.
6. **복식부기 에스크로 기장**: 모든 주문과 정산은 대차평형 원칙에 따라 차변과 대변이 반드시 100% 일치해야 한다.
7. **무결점 상태머신 준수**: 하위 주문(Sub-Order)의 상태 전이는 도메인 상태머신 검증 함수를 반드시 거친다.
8. **멱등성 보장**: 결제 및 주문 생성은 클라이언트가 발행한 UUID 멱등키를 통해 중복 실행을 원천 차단한다.
9. **시크릿 누출 방지**: API Key, 토큰, DB 접속 암호 등 민감 자격증명을 Git 저장소에 절대 커밋하지 않는다.
10. **자동 배포 검증**: 모든 코드는 CI 품질 게이트(테스트, 린트, 드라이런) 통과 후에만 프로덕션에 배포된다.
