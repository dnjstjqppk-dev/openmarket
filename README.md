# OpenMarket Global E-Commerce Platform

Temu 벤치마킹 기반 차세대 글로벌 오픈마켓 시스템
- **Customer Storefront**: Nuxt 3 (SSR/Edge)
- **Admin Console**: Vue 3 SPA
- **Partner Console**: Vue 3 SPA
- **Backend API Gateway**: Go 1.23+ Fiber & Redis 7 Lua Concurrency
- **Database Engine**: PostgreSQL 16 (BigInt Currency, Double-entry Ledger)
- **Edge Infrastructure**: Cloudflare Pages & Workers
