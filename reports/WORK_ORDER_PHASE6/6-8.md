## 1. 무엇을 바꿨나

| 지시 | 구현 |
|---|---|
| 1. 로케일 일관 | hreflang을 BCP47 지역 코드로 전환(ko-KR·en-US·ja-JP + x-default=ko, 저장 로케일·og:locale과 일치). 셸 정적 링크·`hreflangOf`·`og:locale:alternate`(`HREFLANG_LOCALES` 단일원천) 모두 교체. `lang="ko"`·`og:locale=ko_KR`는 기존 유지 확인 |
| 2. 쿼리 canonical | 정렬·필터·추적 쿼리는 전부 제거, `?page=N`(N≥2)만 자기 canonical로 유지(page=1·이상값은 bare URL). `canonicalOf(base, path, query)`+`hreflangOf` 동반, PLP `?page` watcher·JSON-LD canonical까지 추적(무한스크롤·뒤로가기 포함). 서버 `seo-head.js` 미러도 동일 |
| 2. 검색 noindex | `/search`(+미러)는 `noindex,follow`(`robotsOf`), 기존 비공개 경로는 `noindex,nofollow` 유지. 서버 미러도 동일 |
| 3. 제목·설명 | 상품 `상품명 \| 브랜드 \| OLMOA`(브랜드 공백 시 생략), 카테고리 `하위 - 상위 \| OLMOA`(1단계는 대시 없음), 60자 경계 절삭. 상품 설명=본문 추출, 카테고리 설명=사실 조합(하위명·하위 수·상품 수). 서버 `seo-meta.js`도 동일 규칙으로 교체하며 `무료배송 혜택`·`만나보세요` 템플릿 제거(결정-19) |
| 4. alt·깨짐 0 | `galleryAltOf`=상품명 + SKU 옵션값(최대 3·외 N종) + 복수 장 번호. 저장된 판매자 alt가 있으면 우선. 갤러리 3곳(메인·썸네일·전체화면)에 load 실패 시 중립 플레이스홀더 + 죽은 썸네일 제외(원격 폴백 없음) |
| 5. 결정-19 | `twitter:description`을 6-5 태그라인과 동일 문자열로 교체. description·og:description은 6-5에서 이미 태그라인. 셸에서 `무료배송·가장 합리적인 가격·새로운 표준·만나보세요` 0건 확인 |
