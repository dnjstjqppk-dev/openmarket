## Q-1-2 (작업 1-2, 2026-11-13): 커머스 토큰 명시값 4쌍이 완료 기준 4.5:1에 미달

- 지시서 값표(1-2)와 완료 기준("새 토큰 전부 배경 대비 4.5:1 이상")이 서로 맞지 않는다.
- 실측(WCAG 상대휘도, 라이트 배경 흰색 / 다크 배경 22 25 26):
  - light urgent 3.50, light rating 2.01, light soldout 2.83, dark soldout 3.32.
  - urgent를 urgent-soft 배경에 얹어도 3.07이라 어느 의도 배경에서도 4.5에 못 미친다.
- 조치: 값은 지시서대로 정확히 구현(미사용 토큰이라 동작 변화 없음).
  `theme.test.mjs` T03은 4.5를 만족하는 쌍만 검사하고,
  T04는 미달 4쌍의 실측비를 고정한다(기준을 낮춰 통과시킨 것이 아님).
- 운영자 결정 필요: (a) 4개 값을 4.5 충족 값으로 교체, (b) 해당 쌍의 기준을 낮춤(예: 큰 글자·그래픽 3.0),
  (c) 현 상태 유지. 결정 전까지 작업 1-2 판정은 실패로 기록한다.

## Q-1-7 (작업 1-7, 2026-11-13): 새 주소 체계 없이 기존 주소 유지

- 지시서는 "기존 주소는 새 주소로 넘겨준다"고 하나 새 주소 목록이 없어, 기존 주소를 정식으로 유지하고
  리다이렉트를 추가하지 않았다. 라우터 파일은 무변경(S05가 전 경로 고정).
- 메뉴는 명시 구조대로 묶되, 화면이 없는 항목(상품 등록·가격재고 일괄 수정·출금 신청·세금계산서·
  스토어 쿠폰·타임딜 신청·스토어 꾸미기·검수·분쟁조정·정산배치·지급승인·기획전·타임딜·리뷰 등)은
  해당 4단계 작업에서 추가한다. 죽은 링크를 만들지 않기 위함이다.
- 기존 푸터(v1.2.0 표기)와 셀러 모바일 하단바는 셸 서랍 메뉴로 대체되어 삭제했다.
- 운영자 확인 필요: 주소 개편이 필요하면 새 주소 목록 확정.
