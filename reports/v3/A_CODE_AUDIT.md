## 2. 감사 방법

1. 라우트 14개 파일 전수 정독 (인증·금액·상태전이·트랜잭션 중심).
2. **공격 재현 스크립트**로 결함 실증 → `evidence/01_exploit_baseline_before_fix.txt` (수정 전 18/18 취약).
3. 수정 후 동일 스크립트 재실행 → `evidence/03_exploit_after_fix.txt` (0/18).
4. 적대적 보안·무결성 스위트 53개 → `evidence/02_security_integrity_after_fix.txt`.
5. 실제 Workers 런타임(workerd + 로컬 D1)과 실브라우저(Chrome headless, CDP)로 검증 → `evidence/05`, `evidence/06`.
